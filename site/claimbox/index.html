claimbox · the claim language for cert-machine

Claims are written in words no machine can check. claimbox states them so one can.

claimbox is a language, and a translator into it. A sentence from a paper, a README, a leaderboard or an AI’s answer becomes an exact claim: the bytes it is about, how they are read, and each bound as the exact number its digits mean. A person or an AI model writes the claim by its rules; claimbox checks the writing and prints it back in plain words; cert-machine decides it with one of three words, CERTIFIED, REFUTED or REFUSED. When a sentence cannot be stated exactly, the reason is named instead of a guess.

AI models write it · checks decide what counts

13 AI models wrote claims. Every one that passed the checks held.

560 of 560
claims that passed every check, CERTIFIED by cert-machine

Each model was given the same rules and the same 80 AI-written sentences, one at a time, and wrote 600 claims between them. None of the checks is a model: every number must be found in its sentence, the claim must read back with the sentence’s own relation, move exactly when one digit of its bar is moved, and stay put when the sentence is reworded. A claim that fails one is refused and named, and the others still count.

Among the claims the checks refused, 1 was wrong, and the checks refused it before cert-machine refuted it: it is below. Asked 3 times, Gemini 4 Argon wrote the same claim, or named the same hole, for 80 of the 80 sentences. On cert-machine’s register, 11 models wrote 245 claims that passed, and 27 sentences are validated: the grammar and a model, two different kinds of writer, agree. On the AI phrasings 3 are, so far: every model counts as one kind of writer, and the second kind there is a person.

write a claim

One file says what is claimed, about which bytes, read how

The language is small: the source that prints the sentence, the data it is about and how its bytes are read, the definitions it uses, and the claim. A model gets the same rules as a person, written down once in the guide.

source P = notes/my-paper.md
data   f = corpus/my-construction.json
read   f as doubles
use    C_1b v1

claim  my_bound over f
  quote "the construction gives C_1b ≤ 1.5029" from P
  : C_1b ≤ 1.5029
for people and for models

The rules, written once

Copy the bar exactly as printed. Keep the sentence’s relation, read the right way round. Use only the names the library defines over the data. When a sentence states no exact claim, write the hole and its reason: a hole is an answer. The same text is the prompt an AI model is given.

Three ways to use it

for anyone who publishes a number

Say exactly what you claim

Write the claim once in claimbox: the file, its reading, the bound. claimbox prints it back in plain words from the object cert-machine decides, never from what was typed. A reader then knows exactly what was checked, and on which bytes.

Read the language →
for teams whose models write claims

Count only what holds up

Let a model propose, and let claimbox validate. Each number must be found in the source and the claim must read back with the sentence’s relation. The bar is moved and the claim must move with it; the sentence is reworded and the claim must stay put. A second kind of proposer must agree. What fails is named, not hidden.

how it works

From a sentence to one of three words

  1. The sentenceas the author printed it, in a file anyone can open.|D(1)| ≤ 0.82395317
  2. The claimwritten in claimbox’s language: which bytes, how they are read, which bound. If that cannot be done exactly, the reason is named.
  3. The objectthe pinned bytes, their reading, and each bound as the exact number its digits mean, printed back in plain words.
  4. cert-machine’s wordfrom a separate program that shares no code with claimbox: CERTIFIED, REFUTED with the object that breaks it, or REFUSED with the reason.CERTIFIED

cert-machineThe only judge. claimbox never prints a verdict of its own; it shows cert-machine’s.

The grammar of evidenceSolid for decided, dashed for computed, dotted for chosen. The red × only marks a witness.
