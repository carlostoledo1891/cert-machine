What runs in your tab.

The checker is the same program I run on my own machine, carried into this page unchanged, with the 20 files these 5 claims make it read: 258,918 bytes in all. It hashes every file before it trusts one, it does its arithmetic in exact whole numbers and fractions, and it refuses a number it would have to round.

A browser cannot rebuild the long computations behind the bounds, so for those it replays my published record of each one and holds the claim, the record and its own answer to each other. Where they disagree it refuses. The textbook machine shows why checking stays cheap while finding does not.

Why you can trust this

Every word on this page is decided in your tab by the claim checker, the same file the command line runs. The files it reads stay under their sources’ licences: the C82 certificate is R. Pinho’s (MIT); the registry pages are teorth/optimizationproblems (Apache-2.0); the step function is the body of that registry’s pull request 224; the C1c certificate and its README are rozetyp’s (MIT). The rest is this repository’s own, MIT.
