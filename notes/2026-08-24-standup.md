## Owner ruling appended 2026-08-24 — the one rule

> **You can read sin-mfg and any file at any time seeking insights, answers, numbers,
> research, literature, learnings, engine, etc. BUT NEVER EDIT A FILE OR CHANGE THE TREE.**

Recorded verbatim, and encoded in three places so it binds a session that reads any one of
them: `CLAUDE.md` (a top-level section, before the layout — the harness loads it from the
repo root), `CHARTER.md` §"The two things that still block", and the agent's own memory.

The rule is asymmetric on purpose and the asymmetry is the point: **outward is free, inward
is closed.** Reading needs no permission and no announcement; writing is refused even for a
fix that is certainly right. Finding an error there is a REPORT, never a REPAIR — because
that lab's evidence pins files by path and sha256, an edit makes the pin resolve to nothing,
the rung predicate fails, and a certified claim demotes, with no honest repair short of
re-running and re-certifying.

`LIFT.json` + `PROVENANCE.json` + `make drift` are how the rule is kept mechanically rather
than by memory: every copy records its source path and the source sha256 at lift time, and
drift re-hashes both ends. Measured this session: `39 unchanged · 0 source moved · 0 local
edited · 0 source gone`.
