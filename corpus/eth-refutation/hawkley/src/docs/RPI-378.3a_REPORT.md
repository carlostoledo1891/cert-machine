## What Patch 1 proves

```lean
theorem OAI.Bridges.AnthropicETH.ethIsFalse_of_not_positiveRateETH
    (hsim : SimulationHypothesis) (hconv : ConverterHypothesis) :
    ¬ OAI.ParityWL.Complexity.PositiveRateETH → MainResults.ETHIsFalse
```

`PositiveRateETH` is ParityLifts' formal ETH (`OAI/Combinatorics/ParityLifts/SATChoice.lean`):
some rate `δ > 0` that every multitape `Machine` deciding 3-SAT on `encodeFormula` within
`C (L+1)^d 2^{δN}` steps would have to beat. `MainResults.ETHIsFalse` is Anthropic's
`¬ (0 < s 3)`, where `s 3` is the infimum of rates `δ` at which some Mathlib `FinTM2` decides
3-SAT (`IsKCNF 3`: clauses of length ≤ 3, `Nodup`) on `encClauses 3` within `⌊c 2^{δn}⌋₊` steps.

Unconditional results proved along the way (all in `lean/OAI/Bridges/AnthropicETH/`):

| Theorem | File | Content |
|---|---|---|
| `satisfiable_toFormula_iff` | `Lengths.lean` | the translation `toFormula` preserves satisfiability on 3-CNFs |
| `length_le_of_isKCNF` | `Lengths.lean` | a 3-CNF on `n` variables has at most `(2n+1)^3` clauses |
| `encClauses_length_le` | `Lengths.lean` | `|encClauses 3 φ| ≤ 4 (2n+1)^4` |
| `encodeFormula_toFormula_length_le` | `Lengths.lean` | `|encodeFormula (toFormula φ)| ≤ 20 (2n+1)^4` |
| `PolyBound.absorb` | `Asymptotics.lean` | polynomially bounded `f` satisfies `f n ≤ c 2^{εn}` for every `ε > 0`, `c ∈ ℕ` |
| `ethIsFalse_of_forall_inTime` | `Asymptotics.lean` | `(∀ δ > 0, InTime 3 δ) → ETHIsFalse` |
| `time_chain` | `Reduction.lean` | the three stage bounds compose to `poly(n) · 2^{Dδn}` |
| `inTime_of_not_positiveRateETH` | `Reduction.lean` | under H1, H2: `¬ PositiveRateETH → ∀ δ > 0, InTime 3 δ` |

**Quantifier transfer.** Both negated predicates allow one machine per rate. For a target rate
`δ'`, the proof takes ParityLifts' machine at rate `δ = δ' / (2(D+1))`, where `D` is the
converter's uniform degree, so `D δ ≤ δ'/2`; the remaining polynomial factor is absorbed at
rate `δ'/2`.

## What remains conditional

Two hypotheses, stated as `Prop` definitions in `Reduction.lean`. Each one describes a
transformation of machines and stays silent about satisfiability, ETH, and SAT running times.

**H1 `SimulationHypothesis` (target of Patch 2).** Every ParityLifts `Machine` `M` has a Mathlib
`TM2ComputableAux Bool Bool` `N` with finite stack alphabets and a constant `K` (allowed to depend
on `M`) such that `Emits M x s b` gives `TM2OutputsInTime N.tm (x.map …) (some ([b].map …))
(K (|x| + s + 1))`. Planned proof: each tape as two stacks; one ParityLifts step as one TM2 step
(one TM2 step runs a whole statement); input copied off `k₀`; stacks emptied and state reset to
reach `haltList`.

**H2 `ConverterHypothesis` (target of Patch 3).** One exponent `D` for all machines such that
every `M` has `M'` with `Emits M (encodeFormula (toFormula φ)) s b → ∃ r, Emits M'
(encClauses 3 φ) r b ∧ r ≤ C (|encClauses 3 φ| + s + 1)^D` on 3-CNFs. Planned proof:
`Machine.preprocess_run` with one `FCode` converter; its degree `preprocessingDegree` is
independent of the machine, which is what H2 requires.

The uniformity of `D` across machines carries the argument: `¬ PositiveRateETH` supplies a
different machine for each rate, so any overhead exponent tied to the machine would scale with
the rate. (This is also why Anthropic's `Groundwork.exists_tm'`, whose constant `q` fuses degree
and coefficient per machine, suits TSavo's single-machine bridge and needs this alternative route
here.)
