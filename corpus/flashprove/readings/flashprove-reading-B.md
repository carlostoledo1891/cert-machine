- **"The committed model".** In `Sound` and `SoundAndBinding` (Statements.lean:84-134) it means the weights returned by an extractor `Commitment → QueryLog → Option Weights`, applied to the commitment and the committer's own query log. The definition only says such an extractor exists (`∃ extractor`). It is not given the proof, the prompt or the prover's queries, and it may be any function. If it returns `none`, every accept counts as a failure.
- **"The reply" / "output".** A `List Token` (with `Token := ℕ`) that the adversarial prover picks along with the prompt. `IsModelOutput` (Statements.lean:69-72) asks that each listed token be `nextToken` after the prompt plus the earlier output tokens. The empty list always satisfies it.
- **The hash.** `Prob` (VerifiableInference/RandomOracleModel.lean:106-107) integrates over `uniformHash`, a uniform function `List Bool → (Fin 256 → Bool)`. Adversaries are `RandomizedAlgorithm` trees. Only their number of queries is bounded (`QueryBound`); their running time is not. A second hash function, fixed and not random, sits inside the protocol's description (TheSixLines.lean:81; FinalStatement.lean head). `setup` (the public files) and, in completeness and zero knowledge, the weights are quantified outside `Prob`, so they are fixed before the hash is drawn.
- **`PublicSetup`** (TheSixLines.lean:69-75) means three public files with `FilesInUse`: in scope, read, policy `exact`, and `protocolDataWellFormed` passes (FinalStatement.lean:240-248). Exactly one is known: `storedSetup` (TheSixLines.lean:244), whose docstring reads "That these are the files that ship is not said here."
