# The examples' data

Generated by `node design/print/kit.js` in cert-machine. Do not edit: each file names the record it was extracted from
and that record's sha256, and the kit's test (`tests/test_kit.py`, inside the repository) refuses a stale copy.

| file | from | what |
|---|---|---|
| `buoy-a.json` | `certs/hseva-ledger.json` | buoy A's certified return levels of Hs by block for the two families Anderson–Darling picks there, each an enclosure; the delta method's 95% intervals (statistical, computed) |
| `contours-a20.json` | `certs/ecbench-ledger.json` and the pinned `corpus/ec-benchmark` | three submitted 20-year contours of dataset A as their files list them; the 175,320 hours counted exactly into 0.25 s × 0.2 m cells; exact and printed counts outside |
| `gsm8k-501.json` | `certs/gsm8k-ledger.json` | GSM8K test item 501: a step the answer key prints that does not hold, and its exact value |

**Licence.** These are not covered by the kit's MIT licence. The hourly sea states are NDBC's, distributed by the
environmental-contour benchmark (Haselsteiner et al. 2021, github.com/ec-benchmark-organizers/ec-benchmark, commit
`a1561fe7`); only cell counts derived from them are here. The contour vertices are the benchmark participants'
submitted files. GSM8K (Cobbe et al. 2021) is MIT. Use them as the examples use them, with attribution.
