# A share card for /claimbox/, rendered here for the claimbox project to adopt (2026-11-04)

/claimbox/ is claimbox's zone (design/zones.js): built in ~/Projects/claimbox/web by `make web`, never edited here. Its
page carries og:title, og:description and og:url but NO og:image, so a link shared on X shows a text card only.
This folder holds a 1200×630 card (og-claimbox.png, rendered at 2x from og-claimbox.html with the house card recipe: no
numbers in the words) for the claimbox session to copy into its web build and reference as
<meta property="og:image" content="https://carlostoledo.co/claimbox/og-claimbox.png"> plus twitter:card summary_large_image.
The wording is the page's own description. Nothing here writes claimbox; the operator carries it over.
